# 軟體需求規格書 (PRD) - 模組二：影音互動與導讀背誦系統 V2

## 1. 模組概述 (Module Overview)
本模組為「全球化英語 SRS 學習計畫」的核心擴展模組，旨在解決初學者在背誦長篇演講（如史丹佛演講）時的聽力迷失與記憶斷層問題。透過 YouTube API 的精準時間控制，將靜態單字卡轉化為動態的「影音練習器」。

## 2. 資料準備與字幕處理工作流 (Data Pipeline)
由於官方高品質逐字稿（如史丹佛新聞網）缺乏時間軸，而 YouTube 自動字幕雖有時間軸但斷句混亂且缺乏翻譯，因此必須建立一套標準的資料融合工作流 (Data Fusion Workflow)：

1. **取得時間基底**：下載 YouTube 影片的自動產生字幕 (`.vtt` 或 `.srt`) 以獲取精準的 `startTime` 與 `endTime`。
2. **取得高質文本**：獲取演講的官方純文字逐字稿（確保拼寫與標點符號正確）。
3. **AI 對齊與擴充 (AI Alignment)**：由 AI 助手接收上述兩份資料，以官方文本為準進行斷句，並比對 SRT 填入對應的時間軸。同時，AI 負責翻譯成繁體中文、擷取重點單字 (`key_words`) 與撰寫發音提示 (`pronunciation_tip`)。
4. **輸出成品**：直接輸出符合本系統規範的 JSON 檔案（如 `video_Day1.json`），供前端應用程式讀取。

## 3. 核心功能需求 (Functional Requirements)

### 3.1 影音播放控制單元
* **YouTube API 整合**：嵌入固定於頂部的播放器，支援動態載入指定片段。
* **片段鎖定 (Segmented Playback)**：根據 JSON 資料中的 `startTime` 與 `endTime`，前端以高頻率輪詢（如 50ms）控制播放範圍與自動暫停。
* **播放速度調整**：預設提供 0.75x (學習模式) 與 1.0x (原速) 選項。

### 3.2 學習模式切換與邏輯
於上方 Dashboard 提供模式切換開關 `[單字卡 | 影音背誦]`。
| 模式名稱 | 行為定義 | 適用場景 |
| :--- | :--- | :--- |
| **沉浸模式 (Immersive)** | 影片連續播放，下方卡片隨時間自動滾動並高亮對應的中英內容。 | 初步熟悉語感、磨耳朵階段。 |
| **背誦模式 (Drill)** | 影片播完一個句子後自動暫停，顯示中文引導背誦，等待使用者操作。 | 主動式回憶與 SRS 複習階段。 |

### 3.3 針對不懂英文者的輔助機制
* **重點單字提示 (Key Words Display)**：為降低純前端字串比對的複雜度，卡片下方直接列出該句的重點單字，點擊後即時彈出/顯示中文解釋與音標。
* **TTS 雙軌發音**：除了影片背景音外，卡片應附帶 Web Speech API 按鈕，提供純淨的美式發音。
* **Pronunciation Tip 顯示**：於卡片下方即時顯示該句的發音竅門（如連音、不發音位置）。

## 4. 介面與交互設計 (UI/UX Design)

### 4.1 響應式佈局 (Responsive Layout)
* **手機端 (Mobile)**：採用 `100dvh` 固定高度。頂部 30% 為影片區，中部 55% 為互動卡片區（可內部滾動），底部 15% 為固定操作按鈕。
* **視覺風格**：延續 V2 規範之**深色模式**與**玻璃擬物化 (Glassmorphism)**。

### 4.2 操作流程 (User Flow)
1. 使用者選擇 Day X 進入「影音背誦模式」。
2. 影片自動播放片段，並停在第一句末。
3. 使用者看中文背誦後，點擊「Flip」查看英文原文與單字，判定「熟練」或「不熟」。
4. 點擊 SRS 按鈕後，系統紀錄狀態並自動播放下一句。

## 5. 資料結構規範 (Data Structure)
JSON 檔案 (`lessons/video_DayX.json`) 結構規範：

```json
{
  "day": 1,
  "videoID": "UF8uR6Z6KLc",
  "items": [
    {
      "id": "s_001",
      "startTime": 12.5,
      "endTime": 18.2,
      "english": "I am honored to be with you today.",
      "chinese": "我很榮幸今天能與你們在一起。",
      "key_words": [
        {"word": "honored", "meaning": "感到榮幸的", "phonetic": "/ˈɑːnərd/"}
      ],
      "pronunciation_tip": "注意 honored to 的連結讀法"
    }
  ]
}
```

## 6. 動力激勵與管理
* **完課語錄**：每日內容完成後，顯示隨機鼓勵文字。
* **進度隔離**：影音背誦的 SRS 進度與單字卡進度分開儲存於 LocalStorage，避免互相干擾。
